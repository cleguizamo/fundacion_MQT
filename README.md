# Fundación Manos que Transforman

Sitio frontend en Angular para una fundación enfocada en educación, desarrollo social,
ayuda comunitaria, emprendimiento y apoyo a jóvenes y familias vulnerables.

## Desarrollo

```bash
npm install
npm start
```

## Producción

```bash
npm run build
```

El proyecto incluye `netlify.toml` y un formulario compatible con Netlify Forms.
